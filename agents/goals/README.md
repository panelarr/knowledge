# Goals

Briefs for coding sessions: objective, context to read, how to work, constraints and a **Definition of Done** ([template](../../meta/templates/goal.md)). Create one with `python3 tools/kb.py new goal "…"`. A goal is `proposed` when the brief is ready for the owner, `accepted` when dispatched, and `superseded` when replaced by a follow-up goal.
