# Digests

Written by `python3 tools/kb.py ops digest`: one file per run (`YYYY-MM-DD-HHMM.md`), listing open PRs/MRs and issues per registered repo. Items new since the previous digest are marked 🆕, and an **Agent to-do** list ends the file. The agent works through the to-do list in its [ops round](../../playbooks/ops-round.md).

Digests are transient. Keep them committed for a history, or git-ignore them. Delete old ones freely.
